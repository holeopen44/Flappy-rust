## Flappy Circle

A game developed in Java using the libGDX framework.

* `core` - Core game logic.
* `assets` - Textures, audio, and other.

## How to Run

1. Generate a new libGDX project using the official [libGDX Setup Tool](https://github.com/libgdx/gdx-liftoff/releases/latest).
2. Copy the contents of the `core` and `assets` directory from this repository into the directory of your generated project.
3. Open in your IDE and run.
